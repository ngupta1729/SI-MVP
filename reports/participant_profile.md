## Project Idea

An AI agent that studies an existing SaaS product through whatever access is available — the live
product / sandbox (usually available to PMs), plus the code repository and docs (usually not
available to PMs) — and builds a **digital twin / working context** of the product. PMs use that
twin to brainstorm, prototype, and demo feature changes as if they were live, and to test the
product for edge cases. Initial focus: a product called **H5P**.

### Problem space

PMs lack a fast way to deeply understand an existing SaaS product and experiment with meaningful
product changes without engineering access or a full development cycle. Target users: product
managers and product teams working on SaaS products.

### Success criteria

A PM can use the agent to produce a working prototype of a meaningful H5P feature change and demo
it as if live, without engineering access or a full dev cycle. _(Tentative — to be refined in the
Ideation workout.)_

### Starting autonomy level

**L2 — AI as Collaborator.** The AI builds a first-pass digital twin and drafts feature
prototypes/demos; the PM reviews, adjusts, and approves each pass. This is a **starting point, not
a commitment** — the expectation is to level up toward L3 (AI as Agent) as trust in what the AI
can be relied on for grows.
