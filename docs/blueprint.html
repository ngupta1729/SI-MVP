Reworked H5P Smart Import

The educator workflow in four parts, the opportunity tree behind it, and the roadmap — all pointed at one outcome: cut time-to-value, lift week-1 → week-2 retention from ~20%.

1The workflow, in four parts

Each part is a thing the educator does. Below each: what breaks today in the shipped product, and what the rework adds.

−  problem today +  new in the rework Ph2 / Ph3 = lands in a later roadmap phase
Part 1

Express intent

What do I want, from what source?

Today

  • One optional, collapsed box — blank-page problem
  • No guidance on a good prompt
  • Re-typed every import
  • Source goes in as a black box
  • Always generates new questions

Reworked

  • Prompt or guided brief (mutually exclusive)
  • Preset prompts + “improve this prompt”
  • Save-and-reuse prompt / brief library
  • Automatic source read-back — advisory, non-blocking
  • Verbatim question extraction
  • .pptx as a first-class source Ph2
Part 2

Choose what gets made

Activity fit — which types, how many.

Today

  • Blind checkboxes, no fit-to-source signal
  • No item counts, no per-activity config
  • Easy to over-select → overlapping activities
  • No coverage view

Reworked

  • Recommendation engine: feasibility (source) + desirability (intent) + count logic
  • Pre-checked set with item counts + a one-line reason
  • Per-activity mini-controls (count, difficulty)
  • Explicit prompt instructions override the engine
  • Coverage grid: objectives × activities planned
Part 3

Review & refine

Trust it, or fix it — before spend.

Today

  • Credits spent, no preview — black-box wait
  • N separate items; the full editor to fix each
  • No way to tell if a question is correct
  • No targeted regeneration, no natural-language edit
  • No feedback loop

Reworked

  • Review & Approve step + a “Create N” gate
  • Live H5P preview per item (Review + Play)
  • Per-question trust signals: source span, key note, confidence
  • Bounded Refine / Remix / Discard; approve-by-default
  • Inline text edit; refine soft-cap of 3
  • review_event + ImportRecord eval stream
  • Two UI shapes to demo: wizard & 3-panel workspace
Part 4

Find & reuse it later

Where content lives; how it’s traced back.

Today

  • Flat dump into a “Smart Import” folder — in fact two
  • No mapping of which content came from which import
  • No record of what the import was

Reworked

  • Content lands in the library — no dedicated folder
  • from: <import> tag; provenance as a library filter
  • Persisted ImportRecord receipt — survives reload
  • Library lists items across every persisted import
  • Standalone Smart Imports list; lifecycle Ph3

3Roadmap — priority & sequencing

Trust and cleanup first — compounding features only help people who already came back. P0 ship-or-die   P1 core   P2 follow-on.   Seq = build order within the phase.

Phase 1

Fix the cliff — first-run trust + the gate

Gate: W1→W2 retention 20% → 35%+
1 P0 Approval gate: proposed-content list + live H5P preview per item + approve / drop / refine≥ 60% of imports reach an approved set; median generate→approved < 5 min
2 P0 Source grounding per item — show the source sentenceEducator “I could tell if each item was right” ≥ 4 / 5
2 P1 Answer-key justification per itemContributes to approve-without-edit rate ≥ 55%
3 P1 Activity recommendation engine v1 + source read-back panel≥ 50% of imports keep the recommended set; poor-fit selections ↓
3 P1 Verbatim question extraction — Pasted Text, prompt + approval-gate verificationFor question-bearing sources, ≥ 50% choose Extract; edit rate < 10%
4 P2 Known-limitations disclosure at create timeFirst-run on unsupported sources (math / procedural) ↓
Phase 2

Fast & repeatable — returners become regulars

Gate: W2 retention 40%+; imports / active user / week ↑
1 P1 Document ingestion: .pptx + PDF / DOCX (layout-aware, OCR) — file-based extraction rides on this.pptx approve-without-edit reaches clean-article parity
2 P1 Extraction verification pass — extracted item ↔ source-span diffVerbatim-mismatch rate on extracted items < 2%
1 P1 Full intent authoring — prompt-XOR-brief toggle, presets, “improve”Prompt or brief used in ≥ 30% of imports by repeat users
2 P1 Prompt & brief library — system + saved templates, account-scoped, optionally bundling the activity selectionAmong users with ≥ 3 imports, ≥ 40% start from a saved or system template
2 P1 Inline item actions + scoped natural-language editsMedian edits per approved item trends down across a user’s imports
3 P2 Per-activity controls + coverage grid  ·  propagate-a-fix + preference memory  ·  personal track recordCross-activity overlap ↓; same correction made twice → near zero
Phase 3

Stickiness — habit + team expansion

Gate: W4→W8 retention ↑; seats per org ↑
1 P1 Per-session containers + provenance + two-way navigation% of users who re-open a past import ↑; “find last week’s import” task success ≥ 90%
2 P2 Session workspace (refine / add / export / publish set)  ·  choose destination at import timePublished (not just created) rate ↑; ≥ 50% of imports placed outside the default folder
3 P2 Confusion-report loop  ·  assemble into a coherent Interactive Book  ·  org layer (generation policy + org templates)Regenerated-after-confusion rate ↑; ≥ 25% of enterprise authors start from an org template
4 P2 Lifecycle — archive / delete a session + its content togetherPer-active-user folder growth rate ↓
